# div-free

This is the official code repository for our paper.


The repository currently contains three main experiment families:

- `L2` approximation of divergence-free vector fields in 2D and 3D
- homogeneous-boundary Stokes problems in 2D and 3D
- 2D lid-driven cavity flow, together with FEM reference solutions and FEM-vs-FNS comparison

## Environment Setup

Create the conda environment from `environment.yaml`:

```bash
conda env create -f environment.yaml
conda activate div-free
```

After activation, the commands below can be run directly with `python` or `bash`.

## Repository Layout

```text
src/       main entrypoints and implementation
configs/   experiment configs
scripts/   batch runners, drawing scripts, full pipeline
outputs/   generated results and figures (gitignored)
```

Main entrypoints:

- `src/run_experiments.py`: `L2` approximation
- `src/run_experiments_stokes.py`: homogeneous-boundary Stokes
- `src/run_experiments_lid.py`: lid-driven cavity FNS experiments
- `src/run_fem_vs_fns.py`: FEM-vs-FNS comparison

Core modules are organized under `src/divfree/`:

- `common/`: sampling, quadrature, solvers, checkpoint and IO utilities
- `assembly/`: linear-system assembly for `L2` and Stokes variants
- `tasks/`: task-specific runners and logic
- `plotting/`: post-processing and figure generation

## One-Click Full Pipeline

After the environment is ready, we recommend trying the reduced pipeline first to verify that the full workflow runs correctly on your machine:

```bash
EXPERIMENT_SCALE=small SKIP_ABLATION=1 bash scripts/run_all_experiments.sh
```

This command uses the same one-click entrypoint as the full run, but with a reduced problem size:

- in `configs/l2_approx/` and `configs/stokes/`, `experiment.M_list` is truncated at `512`
- in `configs/stokes_lid/`, `fns.n_list` is truncated at `512`
- in `configs/stokes_lid/`, `reference.fem_mesh_N` and `fem_compare.reference_mesh_N` are reduced from `512` to `64`
- in `configs/stokes_lid/2d_stokes_lid_femonly_classic_config.json` and `configs/stokes_lid/2d_stokes_lid_femonly_cos2_config.json`, `fem_compare.mesh_list` is truncated to `2, 3, 4, 6, 9`

It takes around 1h to complete all experiments above on a dual-socket AMD EPYC 9554 server with 128 physical cores.

To run the full-scale pipeline, use:

```bash
EXPERIMENT_SCALE=full bash scripts/run_all_experiments.sh
```

The default is also `full`, so the following is equivalent:

```bash
bash scripts/run_all_experiments.sh
```

The pipeline runs:

- all main experiment sweeps
- all drawing scripts
- both ablation scripts

Outputs are written under `outputs/`. Terminal output is streamed live, and a log file is written to the repository root:

- `run_all_YYYYmmdd_HHMMSS.log`

It takes around 10h to complete all experiments above on a dual-socket AMD EPYC 9554 server with 128 physical cores.

Useful options:

```bash
DRY_RUN=1 bash scripts/run_all_experiments.sh
SKIP_ABLATION=1 bash scripts/run_all_experiments.sh
EXPERIMENT_SCALE=small SKIP_ABLATION=1 bash scripts/run_all_experiments.sh
LOG_FILE=my_run.log bash scripts/run_all_experiments.sh
```

Environment variables:

- `EXPERIMENT_SCALE=small|full`: choose between the reduced pipeline and the original full-scale pipeline
- `SKIP_ABLATION=1`: skip `scripts/ablation/run_boundary_ablation.sh` and `scripts/ablation/run_mass_ablation.sh`
- `DRY_RUN=1`: print the pipeline steps without executing them
- `LOG_FILE=...`: write logs to a custom file instead of the default timestamped log

## Main Experiments

### 1) Divergence-Free `L2` Approximation

This task approximates divergence-free target vector fields on `[-1,1]^d` with function-space neural bases. The repository includes:

- a 2D problem based on divergence-free fields generated from a stream function
- a 3D problem based on divergence-free fields generated by curl-type construction

Run single configs:

```bash
python src/run_experiments.py configs/l2_approx/2d_L2_config.json
python src/run_experiments.py configs/l2_approx/3d_L2_config.json
```

Batch sweep over `k = 1, 2, 3, 4`:

```bash
bash scripts/batch_l2_k.sh
```

Configs:

- `configs/l2_approx/2d_L2_config.json`
- `configs/l2_approx/3d_L2_config.json`

Expected output directories:

- `outputs/l2_approx/2d_L2/divfree2d-nomass-k=<k>/`
- `outputs/l2_approx/3d_L2/divfree3d-mass-k=<k>/`

### 2) Homogeneous-Boundary Stokes Problems

This task solves Stokes problems with homogeneous boundary conditions on `[-1,1]^2` and `[-1,1]^3`. In particular:

- `stokes2d` solves the homogeneous-boundary Stokes equation on `[-1,1]^2`
- `stokes3d` solves the homogeneous-boundary Stokes equation on `[-1,1]^3`

Run single configs:

```bash
python src/run_experiments_stokes.py configs/stokes/2d_stokes_config.json
python src/run_experiments_stokes.py configs/stokes/3d_stokes_config.json
```

Batch sweep over `k = 2, 3, 4, 5`:

```bash
bash scripts/batch_stokes_k.sh
```

Configs:

- `configs/stokes/2d_stokes_config.json`
- `configs/stokes/3d_stokes_config.json`

Expected output directories:

- `outputs/stokes/2d_stokes/stokes2d-nomass-k=<k>/`
- `outputs/stokes/3d_stokes/stokes3d-mass-k=<k>/`

### 3) 2D Lid-Driven Cavity Flow

This task studies steady 2D lid-driven cavity flow on `[-1,1]^2`. The code supports:

- FNS experiments using lid profiles `classic` and `cos2`
- FEM reference computation and reuse
- FEM-vs-FNS convergence comparison

Run FNS lid experiments:

```bash
python src/run_experiments_lid.py --config configs/stokes_lid/2d_stokes_lid_classic_config.json
python src/run_experiments_lid.py --config configs/stokes_lid/2d_stokes_lid_cos2_config.json
```

Run FEM-vs-FNS:

```bash
python src/run_fem_vs_fns.py --config configs/stokes_lid/2d_stokes_lid_femonly_classic_config.json
python src/run_fem_vs_fns.py --config configs/stokes_lid/2d_stokes_lid_femonly_cos2_config.json
```

Batch scripts:

```bash
bash scripts/batch_stokes_lid_k.sh
bash scripts/batch_stokes_lid_femonly.sh
```

Here `scripts/batch_stokes_lid_k.sh` sweeps `k = 2, 3`.

Configs:

- `configs/stokes_lid/2d_stokes_lid_classic_config.json`
- `configs/stokes_lid/2d_stokes_lid_cos2_config.json`
- `configs/stokes_lid/2d_stokes_lid_femonly_classic_config.json`
- `configs/stokes_lid/2d_stokes_lid_femonly_cos2_config.json`

Expected output directories:

- `outputs/stokes_lid/classic-k=2-nomass-fem2-512-lambdy=1e3/`
- `outputs/stokes_lid/classic-k=3-mass-fem2-512-lambdy=1e3/`
- `outputs/stokes_lid/cos2-k=2-nomass-fem2-512-lambdy=1e5/`
- `outputs/stokes_lid/cos2-k=3-mass-fem2-512-lambdy=1e5/`
- `outputs/stokes_lid/femonly-classic-ref2-512/`
- `outputs/stokes_lid/femonly-cos2-ref2-512/`

## Ablation Experiments

### Boundary Ablation

Run:

```bash
bash scripts/ablation/run_boundary_ablation.sh
```

This runs six Stokes configs under `configs/boundary_ablation/` and writes outputs to:

- `outputs/boundary_ablation/stokes2d-nomass/`
- `outputs/boundary_ablation/stokes3d-mass/`

Configs:

- `configs/boundary_ablation/stokes2d-nomass/2d_stokes_config-lambdry=0.01.json`
- `configs/boundary_ablation/stokes2d-nomass/2d_stokes_config-lambdry=1.json`
- `configs/boundary_ablation/stokes2d-nomass/2d_stokes_config-lambdry=100.json`
- `configs/boundary_ablation/stokes3d-mass/3d_stokes_config-lambdry=0.06.json`
- `configs/boundary_ablation/stokes3d-mass/3d_stokes_config-lambdry=6.json`
- `configs/boundary_ablation/stokes3d-mass/3d_stokes_config-lambdry=600.json`

### Mass Ablation

Run:

```bash
bash scripts/ablation/run_mass_ablation.sh
```

This runs two `L2` configs and draws the mass-ablation figures. Outputs are written to:

- `outputs/mass_ablation/divfree2d-mass-k=4/`
- `outputs/mass_ablation/divfree2d-nomass-k=4/`
- `outputs/mass_ablation/mass_ablation_convergence.png`
- `outputs/mass_ablation/mass_ablation_condition.png`

Configs:

- `configs/mass_ablation/divfree2d-mass-k=4_config.json`
- `configs/mass_ablation/divfree2d-nomass=k=4_config.json`
